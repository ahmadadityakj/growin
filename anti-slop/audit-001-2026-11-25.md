# antislop audit 001 — Growin

Mode: after. Scope: seluruh UI yang sudah ship (login, dashboard, leads,
pipeline, outreach, research, follow-ups, reports, integrations, settings).
Auditor: Devin. Tanggal: 2026-11-25.

Yang SUDAH bagus (tidak masuk temuan):
- Tidak ada statistik/testimonial palsu — semua angka dari database (R-17, R-18, R-36 PASS)
- Empty state dipakai luas di semua halaman list (R-27 sebagian)
- Focus ring custom konsisten di semua komponen UI (R-32 outline OK)
- Settings nav mengarah ke halaman nyata yang dilabeli "Segera hadir" (R-24 OK)
- Tidak ada gradient biru-ungu generik; palet emerald mengikuti DESIGN.md

## Temuan

### HIGH (Hard Gate)

1. **R-02 — Em dash di UI text.** ~25 lokasi: metadata titles ("Pipeline — Growin"),
   deskripsi halaman ("…otomatis — berhenti saat…"), separator label, dan
   placeholder sel kosong `"—"`. Contoh: `pipeline/page.tsx:7,50`,
   `follow-ups/page.tsx:49,72`, `integrations/page.tsx:9-11`,
   `kanban.tsx:29,63`, `login/page.tsx:44`. Ganti: judul metadata → "·" atau "|",
   deskripsi → koma/titik, sel kosong → "-".

2. **R-27 — Tidak ada loading state.** Hanya `error.tsx` global yang ada;
   tidak ada satu pun `loading.tsx`. Halaman server-side (leads, research,
   reports) blank/putih saat data di-fetch. Tambah `loading.tsx` minimal di
   route utama atau skeleton di komponen tabel.

3. **R-32 — Kanban drag-drop tidak ada alternatif keyboard.** Kartu pipeline
   hanya bisa dipindah dengan mouse drag. Tidak ada cara keyboard untuk ubah
   stage dari kanban. Mitigasi parsial: status bisa diubah via dropdown di
   halaman Leads/detail — tapi di halaman Pipeline sendiri tidak ada.
   Fix minimal: dropdown status per kartu, atau tombol pindah kiri/kanan.

4. **R-32 — Tombol non-button (Base UI warning).** Warning runtime berulang:
   `Button` dengan `render` ke elemen non-`<button>` sementara `nativeButton`
   true — di Leads, Products, Campaigns, Research, Task detail. Hilangkan
   semantics button; fix: pakai `<button>` di `render` atau set
   `nativeButton={false}` secara eksplisit.

### MEDIUM (Purpose-Gate)

5. **R-05/R-14 — Pipeline: tidak ada empty state khusus.** Saat semua kolom
   kosong, user melihat 6 kolom "0". Tambah banner "Belum ada lead — mulai
   dari Riset atau tambah manual" dengan CTA.

6. **R-26 — Input deal value di dalam kartu draggable.** Klik/drag di dalam
   input angka pada kartu yang `draggable` dapat memicu drag kartu saat user
   seleksi teks. Pisahkan handle drag dari area input, atau nonaktifkan drag
   saat fokus di input.

7. **C-4 — Kontras muted-foreground di latar muted.** Kolom kanban memakai
   `bg-muted/40` dengan teks `text-muted-foreground` — perlu diverifikasi
   ratio ≥4.5:1 (tooling: `contrast-check.py` di skill antislop-human).

### LOW (Quality Locks)

8. **C-1 — "·" separator berlebih.** Beberapa tempat pakai "·" sebagai
   pemisah (industry · city). Konsisten, tapi pastikan bukan default tanpa
   alasan — untuk metadata lead boleh, untuk judul tab browser (temuan 1)
   ganti dengan format "Pipeline | Growin".

9. **R-03 — Kanban di layar sangat sempit.** `grid-cols-2` di mobile berarti
   kolom ~160px; kartu dengan input angka bisa sempit. Pertimbangkan
   `grid-cols-1` dengan kolom collapsible, atau scroll horizontal per kolom.
